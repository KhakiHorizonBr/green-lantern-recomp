Não publique, envie em issues ou pull requests, nem peça aqui ISOs, executáveis originais, chaves, arquivos extraídos do disco, conteúdo descriptografado ou outros materiais protegidos. Não use este projeto para contornar criptografia ou controles de acesso. Remova dados de jogo de logs e relatórios antes de compartilhá-los.

A ausência de uma ISO no repositório não altera os direitos dos titulares sobre o jogo, nem funciona como autorização para criar ou distribuir cópias.
